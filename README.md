# XPPT — Figma 转 PPT 插件

将 Figma 中选中的 Frame 一键转换为可编辑的 PowerPoint（`.pptx`）文件并下载。文字、形状、线条在 PPT 中保持可编辑，复杂的视觉效果（渐变、模糊、遮罩、特殊多边形等）会自动导出为图片，保证视觉一致。

## 功能特性

- **Frame 一键转页**：选中的每个 Frame 自动成为一页幻灯片；无 Frame 时，选中内容合并为一页
- **可编辑输出**：文字、矩形/圆角矩形/圆形、椭圆、星形、三角形、线条均以原生形状输出，可在 PPT 中继续编辑
- **复杂效果图片化**：渐变填充、图层模糊、遮罩、非标准多边形、旋转容器等自动导出为图片，保证视觉还原
- **视觉保真**：支持透明度、投影、描边、虚线、圆角、文字对齐与行高、单行文字防误换行
- **成本预估**：转换前预估内容规模，内容较大时提前提示，避免卡顿
- **可配置输出**：幻灯片尺寸（16:9 / 16:10 / 4:3 / 宽屏）、内容缩放比例（50%–100%）、图片导出精度（1x–4x）
- **智能命名**：默认文件名自动取自选中内容名称
- **进度反馈**：转换与生成过程均有进度提示，完成后自动触发浏览器下载

## 安装插件

1. 打开 Figma 桌面应用，进入 **Plugins → Development → Import plugin from manifest…**
2. 选择本目录下的 [manifest.json](manifest.json)
3. 插件出现在 Plugins 菜单中，之后可随时运行

## 使用步骤

1. **选中内容**：在画布中选中要转换的 Frame 或其他元素
2. **运行插件**：右键 → **Plugins** → **XPPT**（或通过 Plugins 菜单运行）
3. **确认选区**：查看插件顶部的选择列表，确认需要转换的 Frame 已列出；选择有变时可点右上角刷新按钮重新获取
4. **调整设置**（可选）：按需选择幻灯片尺寸、缩放比例和导出精度；点击右上角按钮可在中文 / English 之间切换语言，偏好自动保存
5. **转换下载**：点击「转换并下载 PPT」，等待进度完成，浏览器会自动下载 `.pptx` 文件
6. **检查产物**：用 PowerPoint / WPS 打开，文字与基础形状保持可编辑；如对视觉细节不满意，可调整导出精度后重新转换

## 转换规则

| 操作 | 说明 |
| --- | --- |
| 选中 Frame | 每个 Frame 生成一页幻灯片 |
| 混选 Frame + 其他内容 | Frame 每页一页，其余内容合并为一页 |
| 只选其他内容 | 所有选中内容合并为一页 |
| 幻灯片尺寸 | 16:9（默认）、16:10、4:3、宽屏 16:9 |
| 缩放比例 | 控制内容在幻灯片中占用的比例（50%–100%） |
| 导出精度 | 影响图片类元素的清晰度（1x / 2x / 3x / 4x），精度越高文件越大 |
